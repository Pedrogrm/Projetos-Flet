# Projetos Flet 

Coleção de aplicações desktop/web em **Python** usando o framework [Flet](https://flet.dev), criadas durante meus estudos de programação e desenvolvimento de interfaces.

## Projetos

| Projeto | Arquivo / Pasta | Descrição |
|---|---|---|
| Calculadora de IMC | `imc.py` | Calcula o Índice de Massa Corporal a partir de peso e altura. |
| NooBank | `noobank.py` | Simulação de um app bancário simples. |
| Lista de tarefas | `5_todo/` | App para adicionar, concluir e remover tarefas. |
| App de clima | `6_wheater_app/` | Consulta a previsão do tempo de uma cidade. |
| Gerador | `gerador.py` |
| Gerenciador | `gerenciador.py` |
| Tempo | `tempo.py` cronômetro, relógio, timer |

## Tecnologias

- Python 3
- Flet
- **[CONFIRME se usa outras bibliotecas, como `requests`]**

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Pedrogrm/Projetos-Flet.git
   cd Projetos-Flet
   ```

2. Instale as dependências:
   ```bash
   pip install flet
   ```

3. Execute o projeto que quiser:
   ```bash
   python imc.py
   ```

   Ou, com o CLI do Flet:
   ```bash
   flet run imc.py
   ```

## O que pratiquei

- Construção de interfaces gráficas com Flet
- Manipulação de eventos e estado da aplicação
- Organização de código em Python
