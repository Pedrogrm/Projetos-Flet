## ▶️ Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/Pedrogrm/Projetos-Flet.git
   cd Projetos-Flet
   ```

2. (Opcional) Crie e ative um ambiente virtual:
   ```bash
   python -m venv venv
   venv\Scripts\activate      # Windows
   source venv/bin/activate   # Linux/macOS
   ```

3. Instale as dependências:
   ```bash
   pip install flet
   ```

4. Execute o projeto que quiser:
   ```bash
   python imc.py
   ```

   Ou, com o CLI do Flet:
   ```bash
   flet run imc.py
   ```
